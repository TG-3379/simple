 실행 명령어 요약
 ※ 명령어(옵션)가 추가/변경되면 이 파일도 같이 고칠 것
==================================================================

[실행 위치]  main.py 는 trader 폴더 안에 있음. 터미널이 어느 폴더에 있는지에 따라 앞부분이 다름
  trader 폴더에 있을 때   py main.py --mock
  TGi 폴더에 있을 때      py trader\main.py --mock
  (아래 예시는 trader 폴더 기준. TGi 폴더에서는 main.py 앞에 trader\ 를 붙일 것)
  "can't open file ...main.py: No such file or directory" 가 나오면 위치가 틀린 것
  이동하려면:  cd trader

[기본 실행]
  py main.py                      config.trading.jsonc 의 "실행" 선택대로 실행 (주문은 보내지 않는 dry-run)

[옵션]
  --pick  <이름|번호>              종목선택 방식
  --strategy <이름|번호>           전략
  --buy   <이름|번호>              매수 방식
  --sell  <이름|번호> [...]        매도 방식 (여러 개 가능, 공백으로 구분)
  --live                          모의투자 서버로 실제 주문 전송 (없으면 dry-run: 로그만 출력)
  --mock                          가짜 시세로 흐름만 검증 (키움 연결/인증 불필요)
  --mock-held <N>                 --mock 에서 계좌에 이미 보유 중인 종목 수 (최대종목수 확인 시험용)
  --ticks <N>                     감시 반복 횟수 (0 = 거래시간 종료까지, 기본 0)

  옵션을 주지 않으면 config.trading.jsonc 의 "실행" 값을 쓰고, 옵션을 주면 옵션이 우선

[번호표]
  종목선택  1 조건검색식 / 2 관심종목 / 3 실시간 조회 순위
  전략      1 시가 돌파 / 2 M띠 / 3 5% 이상 상승 / 4 5% 하락
  매수      1 일괄매수 / 2 분할매수
  매도      1 스탑로스 / 2 분할매도

[예시]
  py main.py --mock                                   가짜 시세로 전체 흐름 확인
  py main.py --mock --mock-held 5                     기보유 5종목일 때 매수가 막히는지 확인
  py main.py --pick 3 --strategy 4 --buy 2 --sell 1 2    번호로 선택
  py main.py --pick "실시간 조회 순위" --strategy "5% 하락" --buy 분할매수 --sell 스탑로스 분할매도
  py main.py --live                                   모의투자 서버에 실제 주문

[주의]
  - --live 없이는 주문이 나가지 않음 (로그에 [dry-run] 으로 표시)
  - 실제 키움 호출(--mock 아님)은 kiwoom 패키지(kwcli)가 설치된 환경에서 실행해야 함
  - 새 종목은 계좌 보유 종목 수가 "최대종목수" 이상이면 매수되지 않음
  - 설정은 config.trading.jsonc 에서 바꿈 (종목수/금액/한도/분할/손절 등)
